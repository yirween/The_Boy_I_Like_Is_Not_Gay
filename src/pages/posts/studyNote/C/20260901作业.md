**1. 简述计算机程序的定义，并说明其核心作用。**<br />
&emsp;定义：使用计算机可以识别的语言编写的一系列精心设计的指令
&emsp;作用：可以指导计算机执行特定的任务和特定的问题

**2. 程序设计并非单纯的代码编写，而是一个综合性过程。请说明完整的程序设计流程包含哪些核心阶段。**<br />
&emsp;分析问题 → 设计方案 → 实现方案 → 确保正确运行

**3. 程序设计语言的发展经历了哪三个阶段？**<br />
&emsp;机器语言 → 汇编语言 → 高级语言

**4. 高级语言的翻译方式主要有编译和解释两种，请简要说明二者的本质区别。**<br />
&emsp;编译：将代码整体翻译。需要编译器将源程序翻译为机器代码，再由连接器变为可执行程序
&emsp;解释：由解释器逐条翻译执行

**5. C 语言中的注释有哪两种形式？编译器对注释内容会如何处理？注释的核心作用是什么？**<br />
&emsp;行内注释 和 多行注释
&emsp;跳过
&emsp;方便人理解阅读程序



**6. 一个完整的 C 语言程序的基本结构包含哪些组成部分？**<br />
- 文档说明
- 预编译指令
- 全局变量声明
- 函数声明
- 主函数
- 子函数

**7. 一个完整的 C 语言开发环境通常包含哪五大核心组成部分？请简要说明编译器在开发中的核心作用。**<br />
- 编译器
    - 将C语言源代码编译成机器码
- 集成开发环境
- 文本编辑器
- 调试工具
- 库文件

**8. 编写 C 语言程序，模仿例 1~2 的结构，实现以下功能：**<br />
&emsp;**(1) 输出固定字符串：“欢迎学习 C 语言程序设计！”**<br />
&emsp;**(2) 输出自定义信息（包含你的姓名、学号、班级）**<br />
&emsp;**(3) 输出本章核心语录：“优秀程序员应该有三大美德：懒惰、急躁和傲慢”**<br />
```c
#include <stdio.h>

int main() {
	printf("（1）欢迎学习C语言程序设计！ \n（2）(姓名)(学号) 数媒26 \n（3）优秀的程序员应该有三大美德：懒惰、急躁和傲慢");
	return 0;
}
```
